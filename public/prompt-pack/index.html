First 30 minutes after download

Minutes 0–10: lock the job

Fill intake: one source asset, one channel, one CTA, one reviewer, one success definition (e.g. “15–20s homepage demo ships tomorrow”).

Minutes 10–20: first-pass prompt set

Write one short brief, a 4–6 scene sequence (5–8s each), and one CTA line. Run it on Runway first; keep Pika as fallback only.

Minutes 20–30: repair one failure

Pick one failure mode (generic output, subject drift, flat motion, weak CTA, credit burn). Fix that shot only. Save winning hook + scene order + review note.
